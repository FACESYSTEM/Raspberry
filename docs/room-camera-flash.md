# 個室カメラ（XIAO ESP32S3 Sense）の準備と書き込み

Mac で行う。初回だけ 1〜3 の準備が要る。2 台目からは 4 以降だけ。

## 1. Arduino IDE を入れる（初回だけ）

1. https://www.arduino.cc/en/software から「macOS」版をダウンロードして入れる
2. 開いたら、メニューの「Arduino IDE」→「Settings（設定）」→ 言語を「日本語」にすると読みやすい

## 2. ESP32 を使えるようにする（初回だけ）

1. 左の「ボードマネージャ」（基板の絵のアイコン）を押す
2. 検索欄に `esp32` と入れる
3. **「esp32 by Espressif Systems」**の「インストール」を押す（数分かかる）

出てこないときは、「Settings」→「追加のボードマネージャの URL」に
`https://espressif.github.io/arduino-esp32/package_esp32_index.json` を入れてから探す。

## 3. OV5640 のピント合わせ（OV5640 を使うときだけ）

1. 左の「ライブラリマネージャ」（本のアイコン）を押す
2. `OV5640` で検索し、**「ESP32_OV5640_AF」**を入れる

入れなくても動く（ピントは固定のまま）。付属のカメラ（OV2640・OV3660）には要らない。

## 4. プログラムを開いて書き込む

1. GitHub の `esp32cam/fscam/fscam.ino` を Mac に置き、Arduino IDE で開く
   （フォルダ名 `fscam` とファイル名 `fscam.ino` は同じにしておく）
2. XIAO を USB-C ケーブルで Mac につなぐ
3. 上の「ボードを選択」で **XIAO_ESP32S3** と、つないだ口（`/dev/cu.usbmodem…`）を選ぶ
4. メニューの「ツール」で次を選ぶ
   - **PSRAM: 「OPI PSRAM」**（これを忘れるとカメラが動かない）
   - USB CDC On Boot: 「Enabled」（動いている様子を Mac で見るため）
5. 左上の「→」（書き込み）を押す。下に「書き込みが完了しました」と出れば終わり

書き込めないとき: XIAO の小さな **B（BOOT）ボタンを押したまま** USB-C を挿し直し、もう一度「→」を押す。

## 5. microSD を用意する

1. Mac の「ディスクユーティリティ」で microSD を **MS-DOS (FAT)・マスター・ブート・レコード** で消去する
   （「表示」→「すべてのデバイスを表示」で、カード本体を選ぶ。64GB 前後と出ているものを必ず確かめる）
2. `esp32cam/fscam.txt.example` をもとに、microSD の一番上に **`fscam.txt`** を作る
   - `ssid` と `password`: 店（事務所）の Wi-Fi
   - `hub`: Pi 5 の名前（`fs-pi-test.local`）
   - `cam`: 部屋の名前（Pi 5 で `sudo ./deploy/add-room.sh room1` としたときの `room1`）
   - `key`: Pi 5 で `sudo cat /etc/fservice-pi/hub.key` と打って出た文字
   - テキストエディットなら「フォーマット」→「標準テキストにする」にしてから保存
3. Mac で「取り出し」をしてから、XIAO の差込口に入れる

## 6. 動きを確かめる

1. Arduino IDE の右上の虫めがね（シリアルモニタ）を開き、右下を **115200 baud** にする
2. XIAO の R（RESET）ボタンを押すと、次のように出る
   ```
   fscam-0.1.0 起動
   部屋 room1・Pi fs-pi-test.local:8650・大きさ sxga・毎秒 3 枚
   Wi-Fi につながった（192.168.x.x・電波 -55）
   ```
3. 人感センサーの前で手を振ると「撮影開始」→「撮影終了: n 枚」→「送った」と出る
4. Pi 5 の一覧（スマホで `http://fs-pi-test.local:8650/`）に部屋が出て、写真が見られる

## 7. 2 回目からは Wi-Fi 経由で更新する（USB をつながない）

`fscam-0.2.0` 以降を一度 USB で書き込めば、その後は Pi 5 から Wi-Fi で配れる。

1. プログラムを直したら、`fscam.ino` の `FW_VERSION`（例: `fscam-0.2.0`）の数字を必ず上げる
   （カメラは「自分の版と違う」ときだけ更新する）
2. Arduino IDE の「スケッチ」→「**コンパイル済みバイナリをエクスポート**」（⌥⌘S）を押す
   （`fscam` フォルダの中の `build` → `esp32.esp32.XIAO_ESP32S3` に **`fscam.ino.bin`** ができる）
3. 事務所の Wi-Fi につないだ Mac のブラウザで `http://fs-pi-test.local:8650/` を開く
4. 一番下の「新しいプログラムを配る」で
   - ファイル: `fscam.ino.bin`
   - 配る先: **まず 1 部屋（例: room1 だけ）**
   - 合言葉: `sudo cat /etc/fservice-pi/hub.key` の中身
   を選んで「配る」
5. 1〜2 分で、その部屋のカメラが撮影していないときに取りに来て、更新して再起動する。
   一覧の「プログラムの版」が新しい版になれば成功（更新待ちの間は「旧 → 新（更新待ち）」と出る）
6. 1 部屋で問題がなければ、配る先を「**全部屋**」にしてもう一度配る

- 撮影中は更新しない。microSD に残っている写真は、更新して再起動した後に送られる。
- 更新に失敗したら 10 分後にやり直す（一覧の「失敗の回数」には出ないが、Pi 5 の状態に `fw_err` として残る）。
- 新しい版が起動できなかったときは、電源を入れ直すと前の版に戻る作り（ESP32 の仕組み）だが、
  念のため **まず 1 部屋で試してから全部屋へ**。

## 困ったとき

| 出ること | 直し方 |
|---|---|
| `microSD が使えない` | カードが奥まで入っているか。FAT（MS-DOS）で消去したか |
| `/fscam.txt が無いか…` | ファイル名が `fscam.txt` か（`fscam.txt.txt` になっていないか）。ssid・hub・cam が書いてあるか |
| `カメラを開けない` | 「ツール」の PSRAM が「OPI PSRAM」か。カメラのケーブルが奥まで入っているか |
| Wi-Fi につながらない | 2.4GHz の Wi-Fi か（5GHz にはつながらない）。外付けアンテナが付いているか |
| `送れない（-2）` | Pi 5 が見つからない。`hub=` を Pi 5 の IP アドレスにしてみる |
| `送れない（403）` | 合言葉（key）が違う |
| `送れない（404）` | Pi 5 にその部屋が無い。`add-room.sh` で部屋を足す |
| `時刻が合っていないので撮らない` | Pi 5 につながれば直る |
