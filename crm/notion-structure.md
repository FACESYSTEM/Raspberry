## 2. CRM でのデータの分け方（案）

Notion は 1 行にすべてを詰めている。CRM では「人」「会社」「キャスト」「ボトル」「来店」に分ける。

```
companies 1 ─── * customers * ─── * casts      （customer_casts: 担当レベル）
                     │
                     ├── * bottles             （キープボトル 1 本 = 1 行）
                     └── * visits              （来店 1 回 = 1 行）
```

### customers（顧客）

| 列 | 型 | Notion の元 | 取り込みのルール |
|---|---|---|---|
| id | 連番 | — | |
| guest_no | 整数・一意 | Guest_No. / タイトル | `Gu_` を外して数字だけにする。空ならタイトルの `Gu_(\d+)` から拾う |
| name | 文字 | 個人ゲスト名 | 空ならタイトルから `Gu_番号` と括弧を外した残り |

| birthday | 日付 | 誕生日 | |

| email | 文字 | 顧客メールアドレス | |

## 3. 取り込みで気をつけること

- **Guest_No. が CRM の顧客番号**になる。重複・欠番・`Gu_` の有無を取り込み前に一覧にする
- タイトルの「（自動）」は Notion の自動化で作っているらしいが、古い行は手書き。CRM では guest_no と name から表示名を毎回作る（保存しない）
- `no-data` は「担当なし」として扱い、文字としては残さない
- 元の文字列（ボトル・担当キャスト・備考）は取り込み後も参照できるようにしておく
- 顧客の個人情報なので、取り出したデータ（CSV・JSON）はリポジトリに入れない
